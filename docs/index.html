Scene Studio

Procedural game scenes built layer by layer — terrain, water, planting, furniture, crowds — and, increasingly, written by small models trained on one layer each.

Built by models

Whole scenes from one line →

A director turns one line of description into a brief per segment; separate fine-tuned models write the ground, the planting and the furniture; a verifier decides what ships.

Specialist skies →

Five skies written by a fine-tuned 3B model from one-line descriptions, each one accepted by the verifier that renders and judges it.

Play the hand-built worlds

Beach Walk →

A resort shoreline: surf, sand, hotels, palms and a crowd on the same rig as the player. Walk, jog, jump, look around.

Street Drive →

A suburban street in a small yellow hatchback: parked cars, traffic, houses and pedestrians. Up to accelerate, Down to brake, Left and Right to steer.
